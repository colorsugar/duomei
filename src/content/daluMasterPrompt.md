# 奇幻大陆 · 超大型卫星地图生成总提示词

整合版｜世界地理逻辑 × 七国格局 × 魔法生态 × 战争地理 × 建筑与交互

你是一名同时具备地理学、地质学、气候学、水文学、生态学、军事地理、城市规划、建筑史、世界观设计和高端卫星遥感视觉能力的世界构建与地图生成专家。

请生成一片“西方中世纪幻想大陆”的超大型、高分辨率、可持续缩放的卫星地图。目标不是普通 RPG 地图、桌游地图或装饰性世界地图，而是一颗真正存在过数千年、具有完整自然因果链和文明演化历史的幻想世界。

## 一、最重要的生成原则：先自然，后文明

严格按照以下顺序构建世界，不允许先随机摆城市、国家、怪物，再强行解释位置：

板块运动与地质构造 → 山脉、盆地、裂谷、火山、海沟 → 海岸线、海底地形、洋流 → 纬度、盛行风、季风、海陆热力差 → 气候带、降水、雨影、冰川 → 河流、湖泊、湿地、地下水 → 森林、草原、荒原、沙漠、冻土、海洋生态 → 矿产与资源分布 → 魔法地理与魔力流 → 农业、畜牧、渔业、采矿 → 人口聚集 → 城市、港口、道路、桥梁 → 城堡、宫殿、庄园、学院、神殿 → 贸易网络 → 战争路线、边境、防御体系 → 国家边界 → 历史遗迹、战争创伤和政治格局。

地图必须让人感觉：这些地方只能这样形成，而不是作者随手摆放。

## 二、真实地理逻辑

必须参考现实地球的地理规律：

1. 板块运动形成主要山脉、火山带、断层、盆地和大陆边缘。
2. 大型山脉必须影响降水和河流走向。
3. 河流必须从高处向低处汇流，形成合理的主河、支流、冲积平原和三角洲。
4. 大河流域形成农业核心区与人口密集区。
5. 山脉背风侧形成雨影，可出现干旱草原、荒漠或半荒漠。
6. 沿海地区受洋流影响形成不同温度与湿度。
7. 暖流使部分高纬度沿海地区相对温暖，寒流造成雾、干燥和丰富渔场。
8. 盛行风、季风、山脉和海陆热力差共同决定降水。
9. 高原和高山地区温度降低，形成雪线、冰川和冰川湖。
10. 冰川侵蚀形成 U 形谷、冰碛、峡湾和湖泊。
11. 河流冲积形成平原、三角洲、泛滥区和农业腹地。
12. 港口必须有合理的海湾、水深、潮汐与避风条件。
13. 城市交通必须服从地形，山路、河谷、隘口、桥梁和沿海道路不能违反地形。
14. 资源分布必须与地质结构有关。
15. 战争路线必须受到山脉、河流、森林、沼泽、草原和港口限制。

## 三、七大国家

大陆存在七个主要国家：

1. 艾维诺尔
2. 因维德帝国
3. 机械之心公国
4. 海兽之国
5. 北方荒原之国
6. 瀚海古城与水下公国
7. 半兽人与精灵王国

七国不能只是换颜色的行政区域。每个国家必须有不同的地貌、气候、资源、建筑、经济、军事体系、文化和政治结构。

国家边界优先沿山脉、河流、森林边缘、湖泊、海岸、峡谷等自然界线形成，但允许因战争、殖民、贸易和历史条约出现飞地、狭长走廊、争议地区。

至少三个国家存在明显的内部自治或政治碎片化，例如：

- 偏远港口贵族自治
- 山地领主
- 矿业城市联盟
- 水下贵族与陆地贵族分治
- 森林部族自治
- 边疆军事领

这条走廊应成为两国长期战争的核心地理原因。

## 十五、冰封不是自然冰期，而是禁忌魔法灾难

整个超级帝国的毁灭来自一次强大的禁忌魔法灾难。

不是普通冰河时代。

灾难源于“永恒寒冰核心”。

永恒寒冰核心位于远古帝国地下深处，可能连接：

- 帝国首都
- 魔法塔
- 神殿
- 地脉交汇点
- 古代能源设施

结果：

- 森林冻结
- 河流冻结
- 湖泊冻结
- 城市被冻结
- 军队被冻结
- 皇宫被冻结
- 神殿被冻结
- 道路被冻结
- 地下城市被冰封
- 港口被冻结
- 大量人口瞬间死亡或进入异常保存状态

冰层中能够看到部分古代建筑、树木、船只、军队、城墙和城市轮廓。

冰层内部存在蓝色/透明魔法裂隙。

- 亡灵荒地

这些痕迹必须与历史事件对应，而不是装饰。

## 二十三、魔法地理

在真实地理系统之上加入有限度的魔法地理。

包括：

- 地脉/魔力流
- 魔法晶体矿脉
- 地质断层魔法异常
- 永久雷暴区
- 魔法森林
- 浮空岛
- 魔法污染区

但魔法不能完全破坏自然规律。

每一种魔法异常必须拥有：

- 来源
- 作用范围
- 地理条件
- 运行机制
- 对生态和文明的影响
- 必要时存在代价或限制

## 二十四、贸易网络

建立完整的大陆贸易网络：

- 陆路贸易：粮食、金属、奢侈品、魔法晶体、毛皮、木材。
- 河流贸易：连接农业区、矿业区和王都。
- 海上贸易：连接七国港口、瀚海古城和海兽之国。

贸易路线必须避开：

- 龙巢
- 深沼
- 永久冰原
- 克拉肯海域
- 魔法灾难区

大型贸易路线交汇处形成贸易城市。

## 二十五、建筑与卫星地图可见性

地图不仅要有地形，也要有真实建筑。

必须包括：

- 王宫
- 皇宫
- 城堡
- 山地要塞
- 边境堡垒
- 贵族庄园
- 修道院
- 大教堂
- 骑士团总部
- 港口
- 灯塔
- 魔法师协会
- 学院
- 矿山
- 地下城市
- 古代遗迹
- 桥梁
- 城墙
- 船坞

建筑必须嵌入地形。

卫星远景只能看到城市整体轮廓；中距离能辨认城墙、城堡、港口、道路；近距离必须能辨认主要建筑外观与布局。

## 二十六、交互式地图设计目标

地图最终应适合制作成真正可缩放、可点击的互动卫星地图。

缩放层级：

- 远景：看到整个大陆、海洋、七国、主要山脉和极地。
- 中景：看到国家边界、城市、河流、森林、道路、战争区域、贸易路线和战略点。
- 近景：看到宫殿、城堡、庄园、港口、学院、魔法师协会、矿山、桥梁、灯塔和遗迹。
- 特写：能够辨认大型建筑群的具体外观。

主要建筑和关键地标必须具备明显的视觉特征，方便在地图上点击。

点击建筑后应能打开对应的图文资料：

- 名称
- 所属国家
- 建造年代
- 建筑功能
- 建筑风格
- 历史
- 战争经历
- 当前状态
- 相关人物
- 相关传说

## 二十七、视觉风格

整体必须是：高分辨率卫星遥感风格、真实地形、真实海洋深浅、真实云层、真实河流与湖泊、电影级史诗感、中世纪文明、高幻想、军事地理、古代文明遗迹、自然历史感。

避免：

- 普通游戏地图
- 手绘 RPG 地图
- 平面色块国家地图
- 随机图标堆砌
- 过度卡通化
- 城市随机撒点
- 怪物随机撒点
- 不符合水文规律的河流
- 不符合地形的道路
- 所有国家建筑风格完全相同

## 二十八、最终世界观效果

最终大陆必须让观察者感觉：“这是一个真实存在过数千年的世界。”

任何一座城市都有粮食来源。任何一条道路都有地形原因。任何一个港口都有海洋原因。任何一座城堡都有军事原因。任何一条边界都有自然或历史原因。任何一个矿山都有地质原因。任何一个怪物聚居地都有生态或魔法原因。任何一次战争都有资源、交通、地形或政治原因。任何一个废墟都对应过去的文明与历史事件。

整个大陆必须形成一个闭环：

地质 → 地形 → 气候 → 河流 → 生态 → 资源 → 魔法 → 人口 → 农业/矿业 → 城市 → 贸易 → 军事 → 国家 → 战争 → 历史 → 遗迹 → 再反过来影响今天的政治与地理。

不要生成一张“看起来像奇幻世界”的地图。

要生成一个真正拥有地理、生态、文明、战争、魔法和数千年历史的“奇幻大陆”。
