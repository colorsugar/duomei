与奇幻大陆（V6）不是同一套世界。禁止覆盖 `public/atlas/v6/`，禁止改 `/dalu/map` 交互。

- 用户说「超级大陆」：只动本体系
- 用户说「奇幻大陆」：只动 `/dalu` 与 `public/atlas/v6/`
