- 全部 26 首正选 + 23 首备选（`备选/`）都是 **2026-10-09** 用 **Google Lyria RealTime**（模型 `models/lyria-realtime-exp`，经 Gemini API 的 `BidiGenerateMusic` 实时接口，用户本机已配置的 Gemini API key，免费额度）按提示词实时生成，再在本机做：去掉开头 2 秒、循环曲首尾 8 秒等功率交叉成无缝循环 / 过场曲淡入 1 秒淡出 6 秒、统一响度 -14 LUFS（真峰值 ≤ -2 dBTP）、重采样 44.1 kHz、MP3（2 分钟以上 96 kbps，其余 128 kbps）。
